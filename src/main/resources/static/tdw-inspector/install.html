Rekomendowane dla użytkownika

Fallback dla developerów

Chrome DevTools Snippet

W DevTools otwórz Sources → Snippets, utwórz snippet, wklej kod i uruchamiaj go skrótem Ctrl+Enter. Snippet zawiera pełny runtime i nie pobiera skryptów z TDW.

Scenariusz

Jak używać

  1. Uruchom launcher na badanej stronie. Pojawi się niebieski tryb zaznaczania. Escape natychmiast go zamyka.
  2. Najedź i kliknij element. Klik jest przejmowany przez Inspector i nie uruchamia akcji aplikacji.
  3. Dokończ pytanie w TDW. Zaufany ekran pokaże zredagowany capture, model i reasoning effort.
✓

Minimalny dostęp

Launcher nie ma uprawnień w tle, nie przechowuje ustawień i nie otrzymuje tokenów TDW. Nie zbiera wartości formularzy, cookies, storage, ruchu sieciowego ani screenshotów. Capture nadal traktuj jako niezaufane dane strony i sprawdź preview przed zatwierdzeniem.

Zakładka jest nietypowo duża. Odśwież installer przed ponownym dodaniem zakładki. W razie problemów użyj pełnego DevTools Snippetu.
Szczegóły techniczne i ograniczenia
  • Obsługiwane są zwykłe strony HTTP(S) w top-level dokumencie.
  • CSP może blokować pobranie runtime, a Chrome może poprosić stronę o zgodę na dostęp do lokalnego TDW. Wtedy użyj pełnego Snippetu.
  • Cross-origin iframe i chronione strony Chrome nie są obsługiwane.
  • Popup blocker lub Cross-Origin-Opener-Policy może wymagać ręcznego copy/paste capture.
  • Bookmarklet wykonuje wyłącznie GET statycznych plików z przypiętego originu TDW i nie przekazuje referrera. Kod selektora działa w main world badanej strony i dlatego nie zawiera żadnych sekretów.
