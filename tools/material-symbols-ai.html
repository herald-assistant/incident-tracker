Generowanie z AI

Angular Material · szablon HTML
<mat-icon fontSet="material-symbols-outlined" aria-hidden="true">auto_awesome</mat-icon>

Dołącz font Google Fonts i zaimportuj MatIconModule. W Angularze fontSet wskazuje klasę CSS material-symbols-outlined, a tekst między tagami jest nazwą ligatury.

Import fontu do pliku index.html 
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined&amp;display=block" rel="stylesheet">
