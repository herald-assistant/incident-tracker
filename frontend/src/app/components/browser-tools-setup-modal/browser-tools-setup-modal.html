Dodaj Browser Tools do Chrome

Pokaż pasek zakładek w Chrome, a następnie przeciągnij na niego poniższy element. Na badanej stronie uruchom zapisaną zakładkę i wybierz UX Inspector.

drag_indicator TDW Browser Tools
  1. Ctrl+Shift+B — pokaż pasek zakładek.
  2. Przeciągnij przycisk TDW Browser Tools na pasek.
  3. Otwórz badaną stronę HTTP(S) i kliknij zapisaną zakładkę.

Zakładka uruchamia efemeryczny kod z tej instancji TDW. Nie otrzymuje tokenów, nie działa w tle i znika po zamknięciu narzędzia.
