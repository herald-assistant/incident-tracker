Wskaż element na badanej stronie

  1. Pokaż pasek zakładek w Chrome skrótem Ctrl+Shift+B.
  2. Przeciągnij TDW Browser Tools na pasek zakładek.
    drag_indicator TDW Browser Tools
  3. Otwórz badaną stronę HTTP(S), kliknij zapisaną zakładkę, wybierz UX Inspector i wskaż element.

Zakładka uruchamia kod z tej instancji TDW na czas użycia narzędzia. Po aktualizacji TDW przeciągnij przycisk ponownie, aby odświeżyć zakładkę.
